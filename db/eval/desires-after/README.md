# The after side of the objects-of-desire change

The same three benches as `../desires-before`, four repetitions a side on
`mistralai/mistral-medium-3.1`, against the tree with `Character::Schema` and
`Location::DetailSchema` carrying the four objects of desire and the two
pursuit labels.

This is the baseline the three `BASELINE` constants point at
(`Eval::Genesis`, `Eval::Realization`, `Eval::Dialogue`), so a later prompt
change is judged against it. `../desires-before/README.md` carries the
verdicts and the one thing worth knowing about how the before side was bought.
