# Adversarial repair evaluation

Frozen before/after evidence for NPC agency and arrival context. Read [NPC findings](npc-findings.md), [arrival findings](arrival-findings.md), and [sequential confirmation](confirmation-summary.json). Four repetitions per arm use fixed fictional fixtures and one pinned OpenRouter model. No older baseline was replaced.

The initial NPC instrumentation-failure batch is preserved and excluded from quality comparisons; its unknown charges remain reserved in [budget accounting](budget-summary.json). Runtime integration and repository validation are documented in [PR #175](https://github.com/calebl/text-adventure/pull/175). Lavish review artifacts remain local and are ignored by Git. Candidate hashes identify temporary frozen source checkouts, not published branch tips.

The root manifest describes initial preparation. The NPC instrumentation manifest records later receipt-helper fixes, and confirmation-manifest.json identifies the final runtime-only view addition.

The retained budget helper is `eval-budget-streaming-v2.rb`. The original and v1 copies named in the instrumentation manifest are superseded; their source remains in the [pre-cleanup snapshot](https://github.com/calebl/text-adventure/tree/2586c409d882502e03cb8269d07346b6626a68e1/db/eval/adversarial-20260909), and their hashes and run associations remain in the manifest. NPC progress logs are omitted because every line can be reconstructed from the corresponding JSON results. Raw results, annotations, comparisons, protocols and budget accounting are preserved.
